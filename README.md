# MovieFlix - Movie Website

A modern and responsive movie website developed as part of my Frontend Development internship task.

## Features

- Responsive navigation bar
- Hero/banner section
- Trending movies
- Movie cards
- Movie search
- Genre filtering
- Movie details modal
- Trailer links
- Responsive design
- Hover animations
- Mobile-friendly layout
- Footer

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Genres

- Action
- Comedy
- Horror
- Sci-Fi
- Drama
- Romance

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
